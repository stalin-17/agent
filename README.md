# AI-агент на Agno + DeepSeek

AI-агент на Python, который умеет работать с интернетом, собственной базой знаний, файлами и исходным кодом.

### Что умеет

* 🌐 Искать актуальную информацию в интернете
* 📚 Отвечать по собственной базе знаний (RAG)
* 📁 Читать и работать с файлами проекта
* 💻 Анализировать исходный код с помощью mcp сервера serena
* 🧠 Запоминать историю диалога
* ⚡ Выводить ответы в режиме streaming

### MCP-серверы

* **Filesystem MCP** — доступ к файлам и директориям проекта
* **Serena MCP** — анализ и навигация по исходному коду через LSP
* **Git MCP** — работа с Git-репозиторием *(можно подключить)*
* **Context7 MCP** — получение актуальной документации библиотек *(можно подключить)*
* **Memory MCP** — дополнительная память агента *(можно подключить)*
* **Sequential Thinking MCP** — помощь в сложных многошаговых задачах *(можно подключить)*
